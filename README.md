# Baseline legal

The privacy policy and terms of use for the Baseline iPhone app, hosted with GitHub Pages.

Every file here is generated. The source is `docs/legal/` in the app repository, which is private:
`privacy.md` and `terms.md` are the text, and `build.py` writes these pages from them. Editing the HTML
here directly would be overwritten on the next build, so change the markdown instead.

- https://maxcasella.github.io/baseline-legal/privacy.html
- https://maxcasella.github.io/baseline-legal/terms.html
